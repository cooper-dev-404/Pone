# P一下位图工作台

这是基于 PhotoCraft v0.23.1 的 Mac 编辑器工作台试用包。当前从「P一下」启动，编辑器窗口标题显示 PhotoCraft。实际图层、笔刷、滤镜、曲线、通道、文字、画板和 PSD 编辑由 PhotoCraft 桌面程序提供。工作台提供简体中文配置、面向位图设计的面板布局、可编辑练习稿和自动验收。

## 在 Mac 上试用

打开 `app/P一下.command`，或在仓库根目录运行以下命令。

```sh
bash app/P一下.command
```

首次启动从 PhotoCraft 官方 GitHub 发布页下载通用 macOS 安装包（约 274 MB），核对固定版本的 SHA-256 及应用签名后，安装到此工作台独立的用户目录。需要 macOS 11 或更新版本，官方安装包适用于 Apple 芯片和 Intel。已有同版官方 DMG 可以用 `LAYERLIGHT_PHOTOCRAFT_DMG=/完整路径/安装包.dmg bash app/P一下.command` 使用离线文件。 [上游发布版](https://github.com/storytold/photocraft/releases/tag/v0.23.1) · [上游系统要求](https://github.com/storytold/photocraft/blob/v0.23.1/docs/releasing.md)

工作台的设置、独立样例副本和编辑器版本位于 `~/Library/Application Support/Layerlight Workbench`。首启打开两份可编辑样稿。后续可从编辑器的文件菜单打开自己的项目，也可用 `bash app/P一下.command --examples` 重开样稿。启动器会保留已有设置和用户编辑过的样例副本。

右上角工作区菜单有三个布局：

| 工作区 | 常用面板 |
| --- | --- |
| 位图 · 合成 | 调整、属性、直方图、图层、通道、路径、历史、动作 |
| 位图 · 精修 | 直方图、导航器、笔刷、调整、图层、通道、历史、动作和图层复合 |
| 位图 · 出图 | 图层复合、动作、字符、段落和图层 |

### 从样稿走一遍

1. 打开 [产品合成.psd](../examples/practice/产品合成.psd)，用文字工具修改「新品发布」。选择「主体曲线」，在属性面板调整亮度。它剪贴到带蒙版的商品层，背景保持独立。
2. 打开 [精修素材.png](../examples/practice/精修素材.png)，新建空白图层，开启采样所有图层。用污点修复去掉右上圆点，或者选仿制图章，从干净背景取样再修掉圆点。
3. 打开 [横竖版交付.pcraft](../examples/practice/横竖版交付.pcraft)，通过文件菜单中的画板导出一次生成两张 PNG。竖版保留透明区域。

## 内容识别填充

在仓库根目录运行 `bash app/P一下.command --fill` 打开一份练习副本。画面右侧的红色纸屑和阴影覆盖着镜头旁的布纹。可以用套索圈住纸屑和阴影，也可以从「选择」菜单载入「纸屑选区」。 [练习稿](../examples/practice/内容识别填充练习.pcraft)

1. 打开「编辑 → 内容识别填充」，观察采样叠层和预览。把采样设为「自定义」，用采样画笔在纸屑上方、下方和右侧标出邻近布面。使用减号画笔排除镜头、阴影或其他杂物。
2. 在这张练习稿里，可试把「颜色适应」设为「无」，对比预览的布纹。将输出设为「新建图层」并确认。可在图层面板开关修复层，降不透明度或在修复层上继续修片。
3. 需要快速试填时，在「动作」面板播放「P一下 · 内容识别填充」里的「当前选区 · 填充到新层」。它使用选区周围的矩形区域，采样可见图层，并生成独立修复层。已有配置可从「动作」面板菜单载入动作。 [内容识别填充动作集](<../app/presets/P一下 内容识别填充.atn>)

分层成稿保留布面原片和自定义采样生成的修复层，可开关对照。练习使用生成的产品图加纸屑作为测试样本，便于对照加纸屑前的布面。放大可见局部纤维与参考图存在差异。 [可编辑成稿](../tests/evidence/内容识别填充成稿.pcraft) · [无纸屑参考图](../tests/evidence/内容识别填充参考.png)

## 移除工具

在仓库根目录运行 `bash app/P一下.command --remove` 打开练习副本。画面右侧有一片红色纸屑，下方有一条深色纤维。 [移除工具练习](../examples/practice/移除工具练习.pcraft)

1. 打开工具栏的修复工具组，选择「移除工具」。确认顶部选项栏已勾选「对所有图层取样」和「创建新图层」。首次创建的工作台配置会预先勾选这两项，已有配置可以在选项栏启用。
2. 用约 12 px 的笔刷沿红纸屑和投影外围画一圈，回到起点后松笔。用约 19 px 的笔刷沿深色纤维涂一笔。选择自己的素材时，让笔刷覆盖瑕疵和紧邻的阴影。
3. 要把多笔放在同一修复层，取消「每笔后移除」。画完后按回车或点选项栏的勾号，一次应用全部笔划。按 Esc 可以取消还未应用的笔划。用撤销恢复最近一次应用，也可隐藏修复层来检查原片。

分层成稿将两笔合并应用，修复层保留在原片上方。可在图层面板单独开关和调整不透明度。 [移除工具成稿](../tests/evidence/移除工具成稿.pcraft)

## 文字工具使用本地字体

文字工具会在启动时读取 macOS 可用字体，包括用「字体册」安装的用户字体。要选字体，按 `T` 启用文字工具，选中文字图层，在顶部选项栏搜索字体名称并选择字重。新配置的「位图 · 出图」工作区默认打开「字符」标签。已有工作区可通过「窗口 → 字符」打开同一套字体选择器。

安装或启用新的 `.otf`、`.ttf` 等字体后，退出并重开工作台刷新列表。`.pcraft` 和 PSD 记录文字图层使用的字体。换电脑继续编辑时，在新电脑安装同一字体，或通过「文字」菜单的缺失字体命令选择替代字体。

### 交接前检查字体

打开 `tools/字体检查.command`，选择 PSD、PSB 或 `.pcraft` 源稿。报告会在默认浏览器打开，列出缺失字体名、对应画板和分组下的图层，以及图层的显隐状态。报告检查已保存主文档中的可编辑文字图层，只读取源文件。安装字体或在「文字」菜单中替换字体后，可以重新检查并复查换行。

检查工具使用已安装的 PhotoCraft 和 Python 3.9 或更新版本。报告默认保存在工作台数据目录的 `Reports` 下。在终端可以一次检查多份稿件。

```sh
bash tools/字体检查.command examples/practice/产品合成.psd examples/templates/商品上新模板.pcraft --output ./字体报告
```

## 在轻纱边缘上检查蒙版和溢色

在仓库根目录运行 `bash app/P一下.command --retouch`，会打开一份 920 × 640 的练习稿。纱面中间透出青绿色背景，边缘伸出细丝。可以从同一选区试三种处理，观察换底后哪里仍有残色。 [半透明边缘练习](../examples/practice/半透明边缘练习.pcraft)

1. 选中「轻纱原片」图层，通过「选择」菜单载入已存的 Alpha 通道「起始选区 · 色彩范围」。处理自己的图时，可以先用「色彩范围」吸取背景色，再反选得到主体。
2. 在「窗口」菜单打开「动作」，展开「P一下 · 边缘精修」。在下表选一个动作并按播放。每次运行都会生成带像素蒙版的新图层，并隐藏原图层。要比较另一种处理，可撤销这次动作，再从相同选区运行。
3. 选中新图层的蒙版缩略图，可以用画笔补回或擦去细节。想自己控制细化半径、羽化和去边色强度时，从「选择」菜单打开「选择并遮住」，以黑底和白底预览检查边缘。

| 动作 | 适用情形 |
| --- | --- |
| 选区转蒙版副本 | 直接把当前选区转为灰阶蒙版，可用作前后对照 |
| 细化边缘 · 蒙版副本 | 用 4 px 智能半径细化边缘，适合检查细丝和软硬交界 |
| 细化并去边色 · 蒙版副本 | 在同样的边缘处理上以 75% 强度减轻原背景的残色 |

若已有自定义动作且面板中找不到这个动作集，可从「动作」面板菜单载入包内的 ATN。 [边缘精修动作集](<../app/presets/P一下 边缘精修.atn>)

要直接检查成品，打开下方成稿，在「图层复合」面板切换「原片」「透明底」「白底预览」和「黑底预览」。放大观察纱面透光和游离细丝，选中「去边色 · 可编辑蒙版」的蒙版即可继续改。练习用合成轻纱验证半透明边缘。当前引擎的自动「细化发丝」按钮呈灰色，真实发丝和毛绒的手工修边效果仍待验证。 [半透明边缘成稿](../tests/evidence/半透明边缘成稿.pcraft)

## 批量出图

保存稿件后打开 `tools/批量出图.command`，选择出图内容、源稿和交付目录。批量入口使用已安装的 PhotoCraft 运行时和 Python 3.9 或更新版本。每次运行都会新建一个交付文件夹，并生成逐份文件的尺寸、格式与色彩配置清单。

- **单画布源稿**默认生成 1080 × 1080 方形 PNG、1080 × 1350 竖版 PNG 和 1920 × 1080 横版 WebP。前两份等比留透明边，横版居中裁切。
- **画板项目**按每个画板的原尺寸生成 PNG 和 WebP。可以在原项目里为每个发布渠道单独排版。
- **自定义**可以复制修改 [批量预设](../tools/batch_recipe.json)。单画布的 `fit` 支持 `contain`（等比留边）和 `cover`（居中裁切）。`format` 支持 PNG、JPG 和 WebP，JPG 和 WebP 可设置 `quality`。
- **原生导出**可以在新建工作台配置的「文件 → 导出 → 导出为」使用 PNG 原尺寸、JPEG 高质量、WebP 网页和 PNG @2x 四个预设。

从终端批量处理多份稿件时：

```sh
bash tools/批量出图.command --output ./成品 examples/practice/产品合成.psd examples/practice/横竖版交付.pcraft
bash tools/批量出图.command --recipe ./自定义预设.json --output ./成品 ./设计稿.psd
```

批量导出读取已保存的稿件。引擎先在原色彩空间合成，再保留透明度转换为 sRGB。每张成品会重读并核对实际尺寸和嵌入的 ICC。一次任务中存在打不开的稿件或源稿在处理中被改写时，程序会报错并清理该次交付的暂存文件。

### 图层与切片素材

- **图层**。在图层面板把要出图的可见图层或组命名为 `导出: 商品透明图`。标记后的文字或组名就是成品基础名。可标记画板内和分组内的图层。目标图层或组独立渲染并裁去外围空白，保留其蒙版形成的透明边。需要一起渲染剪贴调整和商品层时，把它们放进同一个标记组。
- **切片**。在编辑器里创建并命名图像切片后保存。每个图像切片从完整合成画面裁出，采用源稿保存的矩形。重叠切片各自保留完整范围。
- 在「批量出图」选择「标记图层」「图像切片」或「图层与切片」，输入 `1,2` 等倍率。默认出 PNG 与 WebP。成品名带序号和 `@1x`、`@2x` 等倍率，同名素材也会各自保留。清单记录图层路径或切片坐标。

可以直接用含两个标记图层和两个重叠切片的样稿试跑。 [素材出图样稿](../examples/practice/素材出图.pcraft)

```sh
bash tools/批量出图.command examples/practice/素材出图.pcraft --mode assets --scales 1,1.5,2 --prefix 商品页 --output ./素材成品
```

## 多画板批量套版

在 Mac 上打开 `tools/批量套版.command`，依次选择模板、CSV 和成品目录。套版使用已安装的 PhotoCraft 运行时及 Python 3.9 或更新版本。可以直接选用 `examples/templates/` 中的商品上新模板和商品清单。样例为两个色款分别生成横版横幅、竖版海报和社媒方图。 [商品上新模板](../examples/templates/商品上新模板.pcraft) · [商品清单](../examples/templates/商品清单.csv)

1. 按渠道在同一份 `.pcraft` 稿件中做好各画板的排版。将需要替换的文字图层或嵌入式智能对象命名为 `{{字段}}`，例如 `{{标题}}`、`{{商品图}}`。同名图层会取同一列数据，各自保留已有的位置和样式。
2. 从表格软件导出 UTF-8 CSV。用 `name` 列为每组稿件命名，其余表头与占位字段一致。每行对应一组设计。图片填相对 CSV 的路径或绝对路径，支持 PNG、JPG、WebP、TIFF。留空的文字列会清空对应的文字。
3. 每组输出一份可编辑 `.pcraft`，以及每个画板原尺寸的 sRGB PNG 和 WebP。默认将素材等比放入原智能对象的内嵌画布。清单记录文件、尺寸和色彩配置，也标出检测到的缺失字体或文字溢出。

若复制的多个智能对象共享同一份内容，请给它们同一个占位名。需要分别换图时，使用「通过拷贝新建智能对象」得到各自独立的内容。使用 `--fit cover` 可以将图片改为居中裁切，使用 `--recipe` 可以自定义画板输出格式。

```sh
bash tools/批量套版.command examples/templates/商品上新模板.pcraft examples/templates/商品清单.csv --output ./套版成品
```

## 链接素材交接

保存源稿后打开 `tools/链接素材.command`。选择「检查链接」，报告会显示素材路径、对应的画板和分组图层，以及这台电脑能否读取。断链可在编辑器里选中对应的智能对象，从「图层 → 智能对象」重新链接到文件。共享同一内容的实例会一同更新，各自保留原有变换。

选择「打包交接」会生成一个新文件夹，里面有可编辑的 `.pcraft`、`Links` 素材目录和引用清单。交接时移动整个文件夹。链接相对稿件定位，同一来源只复制一次，同名文件会分别保存。遇到断链或不可读的素材时会提示重链，交接包在检查通过后才发布。

工具需要 PhotoCraft 和 Python 3.9 或更新版本。支持用 PSD、PSB 或 `.pcraft` 作为输入，由引擎读取主文档可识别的外部链接。作为素材置入的另一个项目若有自己的外部链接，需先整理该素材内部的链接。

```sh
bash tools/链接素材.command check ./商品稿.pcraft
bash tools/链接素材.command package ./商品稿.pcraft --output ./交接
bash tools/链接素材.command package ./商品稿.pcraft --relink 12 ./新位置/商品.png --output ./交接
```

`--relink` 的图层编号可从检查报告取得，替换写入交接包内的稿件。

- Linux Cloud 桌面打开了同一个官方版本及工作台配置。合成布局、双列工具和常驻的调整、图层与历史面板实际显示。界面完成标题修改并保存，重新读取 [桌面改稿 PSD](../tests/evidence/桌面改稿.psd) 确认标题仍是文字图层，曲线剪贴及原图蒙版结构保留。也独立在桌面画布中拖动了曲线控制点。
- 自动验收涵盖 PSD 文字和曲线回改、独立修复图层、组混合和蒙版、16 位 PSD 重开，以及批量成品的尺寸、透明度和 sRGB。套版验收重开了两份源稿，核对文字可编辑性、智能对象变换和三个画板的尺寸，并验证文字溢出提示和失败清理。 [自动验收结果](../tests/evidence/cli-results.json)

- 链接交接样本验证了断链定位、重链保留变换，以及同名素材、共享实例和整包搬移后的重新读取。Mac 文件选择留待实机验收。 [自动验收结果](../tests/evidence/cli-results.json)
